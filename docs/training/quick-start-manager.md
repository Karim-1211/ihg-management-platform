# Quick Start — Manager

## Your 5 Most Common Tasks

**1. Check the Dashboard:** **Dashboard** — occupancy, orders, revenue, and anything needing attention, at a glance.

**2. Review performance:** **Reports** → pick a tab (Executive/Hotel/Restaurant/Delivery/Inventory/Operational) → pick a time period.

**3. Manage a policy:** **Business Rules** → click a policy → view/change its value. Changes are recorded automatically.

**4. All hotel/restaurant tasks:** you can also do everything Receptionist, Housekeeping, Waiter, and Kitchen do — see their quick starts.

**5. Ask the assistant:** click the chat icon → "Give me today's business summary" or "Is anything unusual going on?"

## If Something Goes Wrong

- You only see your own hotel's data — that's expected, not a bug.
- Can't create a Global rule? Only Admin can — you can create hotel-scoped rules.
