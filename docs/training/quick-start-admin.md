# Quick Start — Admin

## Your 4 Most Common Tasks

**1. Everything a Manager does**, but across **all** hotels and restaurants, not just one — see the Manager quick start.

**2. Manage Global rules:** **Business Rules** → create with scope **Global** — applies platform-wide unless a hotel/restaurant has its own override.

**3. Create staff accounts:** assign new staff to the correct hotel/restaurant and role.

**4. Import historical bookings:** use the CSV import tool (Admin-only) — always check the row-by-row report before assuming it succeeded.

## If Something Goes Wrong

- CSV import rejecting most rows? Check date format (YYYY-MM-DD), non-negative amounts, and exact hotel/room name matches.
- A duplicate booking reference in your CSV is rejected, never overwritten — that's intentional.
