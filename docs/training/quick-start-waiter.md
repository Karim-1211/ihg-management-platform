# Quick Start — Waiter

## Your 5 Most Common Tasks

**1. Manage tables:** **Tables** → update status (Available/Occupied/Cleaning).

**2. Progress a dine-in order:** **Orders** → confirm it (sends to kitchen) → once kitchen marks it Ready, mark **Served**.

**3. Assign a delivery driver:** **Deliveries** → find a Ready order → assign an available driver.

**4. Handle a reservation:** **Reservations** → update status when guests arrive (e.g., **Seated**).

**5. Check a bill:** **Bills** — generated automatically once an order is Served.

## If Something Goes Wrong

- Can't mark a delivery order Served? That happens automatically once the driver marks it Delivered — you don't do it manually.
- No drivers to assign? Check with your Manager about scheduling.
