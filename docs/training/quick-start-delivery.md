# Quick Start — Delivery

## Your 1 Main Task

**Complete a delivery:** **My Deliveries** → when assigned, mark **Picked Up** → then **Out for Delivery** → then **Delivered**.

Marking **Delivered** automatically completes the order and generates the customer's invoice — nothing else to do.

## If Something Goes Wrong

- Can't update a delivery? You can only update deliveries assigned to you.
- A completed delivery still showing? Refresh the page.
