# Quick Start — Housekeeping

## Your 3 Most Common Tasks

**1. Complete a room-cleaning task:** **Housekeeping** → find the room → mark **Done** once cleaned. This makes the room bookable again.

**2. Handle a service request:** **Service Requests** → work the request → mark **Completed**.

**3. Record supplies used:** **Inventory → Manage** on an item → choose Purchase/Waste/Adjustment/etc. → enter quantity → **Record**.

## If Something Goes Wrong

- Missing a task for a room you know needs cleaning? Tasks are created automatically at checkout — tell your Manager if one's missing.
- Only mark a task **Done** once the room is genuinely ready — it becomes bookable immediately.
