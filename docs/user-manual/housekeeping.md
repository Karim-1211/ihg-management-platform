# Housekeeping Guide

## 1. Quick Start

Your main screens are **Housekeeping** (room cleaning tasks) and **Service Requests** (guest requests like extra towels or room cleaning). Your job is to work through pending tasks and mark them done.

## 2. Logging In

1. Go to the login page.
2. Enter the email and password given to you by your manager.
3. Click **Log In**.

## 3. Navigation

Your sidebar shows:
- **Housekeeping** — room cleaning tasks
- **Service Requests** — guest requests
- **Inventory** — view current stock levels
- **Notification Settings** — control which notifications you receive

## 4. Daily Tasks

### Completing a Housekeeping Task
1. Go to **Housekeeping**.
2. You'll see a list of pending room-cleaning tasks (these are created automatically when a guest checks out).
3. Once you've cleaned the room, mark the task as **Done**.

Marking a task Done automatically makes the room available again for new bookings.

### Handling a Service Request
1. Go to **Service Requests**.
2. You'll see pending requests like Room Cleaning, Extra Towels, Water, or Amenities, with the room number and guest name.
3. Once you've fulfilled the request, mark it as **Completed**.

## 5. Status Meanings

**Housekeeping Tasks:** Pending · In Progress · Done

**Service Requests:** Pending · In Progress · Completed

## 6. Common Problems

| Problem | What to do |
|---|---|
| I don't see a task for a room I know needs cleaning | Housekeeping tasks are created automatically at checkout — if one's missing, tell your Manager or Reception |
| A service request has no room number showing | This can happen if the request isn't linked correctly — escalate to your Manager |

## 7. Important Notes

- Marking a housekeeping task Done makes the room available for booking again — only mark it Done once the room is actually ready.
- Some service requests (like Food) may have a price attached — this gets added to the guest's final bill automatically when completed.

## 8. Your Permissions

As Housekeeping staff, you can view and update housekeeping tasks and service requests, and view inventory stock levels. You cannot access bookings, billing, or restaurant-side screens.
